## 📋 確認ポイント

### 1. スキーマの一致
- [ ] マイグレーション数が本番と同じか
- [ ] 主要テーブルが全て存在するか
- [ ] ビューが正常に動作するか

### 2. データの状態
- [ ] マスターデータが存在するか
- [ ] テストデータが適切か
- [ ] 本番データが混入していないか

### 3. 同期状態
- [ ] 本番環境より古いスキーマではないか
- [ ] ローカルの最新マイグレーションが適用されているか

---

## ⚠️ 開発環境特有の注意点

### データについて
- 開発環境には本番データを**入れない**こと
- テストデータのみ使用する
- 個人情報を含めない

### マイグレーションについて
- 開発環境で新しいマイグレーションをテストする
- テスト後、本番環境に適用する

### 同期方向
```
ローカル開発 → 開発環境でテスト → 本番環境に適用
```
